Автоматизированные тесты проверки вёрстки главной страницы https://academy-of-life.ru

## Что проверяется

- Цвета (кнопки, заголовки, фон)
- Шрифты (название, размеры, веса)
- Структура страницы (хедер, футер, отсутствие overflow)
- Hover-состояния
- Базовая доступность (a11y)
- Адаптивность (4 разрешения)
- Мобильная вёрстка (бургер, touch-цели)

## Стек

- Python 3.10+
- Playwright
- Pytest
- Allure
- pytest-xdist

## Установка

```bash
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt
playwright install chromium firefox

## запуск
pytest                   # все тесты
pytest -k Chrome         # только Chrome
pytest -k Firefox        # только Firefox
pytest -k Desktop        # только десктоп
pytest -k Mobile320      # только минимальный мобильный
pytest -q -n 2           # параллельно (осторожно — сайт не любит много запросов)

## Отчет Allure
allure serve allure-results

## Что покрыто
Цвета ключевых элементов (кнопка, заголовок, фон)

Типографика (шрифты, размеры, веса, адаптивность)

Структура страницы (хедер, футер, отсутствие overflow)

Hover-состояние главной CTA-кнопки

Базовая доступность (lang, title, alt у изображений)

Адаптивность на 4 разрешениях (1440×900, 768×1024, 390×844, 320×800)

Мобильная вёрстка (бургер, touch-цели ≥ 44px)
