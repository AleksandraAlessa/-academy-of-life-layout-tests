Автоматизированные тесты проверки вёрстки главной страницы https://academy-of-life.ru

## Что проверяется

- Цвета (кнопки, заголовки, фон)
- Шрифты (название, размеры, веса)
- Структура страницы (хедер, футер, отсутствие overflow)
- Hover-состояния
- Базовая доступность (a11y)

## Стек

- Python 3.10+
- Playwright
- Pytest
- Allure

## Установка

```bash
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt
playwright install chromium firefox

## запуск
pytest                   # все тесты
pytest -k Chrome         # только Chrome
pytest -k Firefox        # только Firefox

## Отчет Allure
allure serve allure-results
